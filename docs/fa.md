# زمان

زمان یک افزونهٔ کروم برای ترجمهٔ کردی سورانی و کرمانجی و چند زبان دیگر است. عبارت‌های رایج از واژه‌نامهٔ آفلاین و روی همین دستگاه پاسخ داده می‌شوند. برای جمله‌های دیگر به [کلید AIML](https://aimlapi.com/) خودتان نیاز است. افزونه کلید همراه ندارد.

زمان با کلیک یا فقط انتخاب متن باز نمی‌شود. ترجمه با راست‌کلیک روی متن انتخاب‌شده و گزینهٔ **Translate with Ziman**، یا با میانبر `Alt+Shift+Z` انجام می‌شود. `Alt+Shift+X` زبان مقصد را عوض می‌کند.

## نصب

```bash
git clone https://github.com/sadrmanesh/ziman-ai.git
```

در `chrome://extensions/` حالت Developer را روشن کنید، **Load unpacked** را بزنید و پوشه‌ای را انتخاب کنید که `manifest.json` در آن است.

«سڵاو» را به انگلیسی ترجمه کنید؛ پاسخ باید Hello و از واژه‌نامهٔ آفلاین باشد.

## واژه‌نامه و هوش مصنوعی

واژه‌نامه ۱۰۵ عبارت در پنج زبان (سورانی، کرمانجی، انگلیسی، فارسی، عربی) دارد. قواعد یکدست‌سازی حروف از [persian-rag](https://sadrmanesh.github.io/persian-rag/) آمده است. متن انتخاب‌شده فقط وقتی به `https://api.aimlapi.com` فرستاده می‌شود که ترجمهٔ هوش مصنوعی را خودتان بخواهید. کلید فقط در `chrome.storage.local` می‌ماند.

جزئیات بیشتر به انگلیسی در [شروع کار](getting-started.md) و [حریم خصوصی](privacy.md) است.
